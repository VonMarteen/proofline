# Proofline — Official Brand System

Reference supplied by product owner: `proofline-brand-board.png`.

## Core palette

- Teal — `#22D3A8`
- Mint — `#66F0C4`
- Deep Navy — `#0E141B`
- Slate — `#1B2230`
- Off White — `#F2F4F7`
- Text Gray — `#A3ADC1`

## Product rule

The Proofline product shell keeps the Proofline identity in Commercial, Workspace, Control, Support, authentication and participant chrome.

Customer-specific branding remains scoped to the participant assessment controls, customer identification and generated deliverables. It must not recolor the Proofline Workspace, Control or Support applications.

## Assets

- `proofline-mark.png` — transparent standalone mark extracted from the approved brand board.
- `proofline-app-icon.png` — dark rounded application badge.
- All frontend applications receive the same assets in their `public/` directory.
- File-based `app/icon.svg` is replaced so browser tabs cannot fall back to the previous Proofline icon.
